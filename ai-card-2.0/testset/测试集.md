## 横切验收点（每条用例默认附带）

- 四尺寸（3x3/6x3/3x6/6x6）都有该功能的路由，3x3 至少保留清晰入口；固定风格 珊瑚橙 · Financial 不得更改
- agent 相关状态完整：idle / loading（可取消）/ ok / stale（带时间）/ error（可重试）/ blocked（带原因）
- agent 结果持久化并带时间戳，reload 后仍在；render / resize / reconnect 不重复触发 agent 调用
- agent 输出按不可信文本渲染（createTextNode），结构化输出先校验再使用；链接只能以文本展示（运行时禁止 a 标签）
- findings 对每个 deliveryRequirement 给出 passed / failed / unverified / blocked，不得缺省为 passed

- 含糊：我想要一张能帮我看邮件的智能卡片。
- 加约束：邮箱摘要卡 + AI 总结：总结不超过 60 字；3x3 只显示未读数和总结第一条；邮箱没连上时按钮要禁用并提示先连接。

**夹具 / 断言提示**

- fixtures.http：200 / 403 / 404 三组
- storage 种子：30 天历史 + 5 天历史两套

- 只显示接口真实返回的指标（次数 / token / 剩余额度 / 重置时间），缺失指标显示「暂无」，不推算不虚构
- 每日采样写 storage 历史（保留 30 天），同日重复不新增；今日/本月汇总与趋势 SVG 本地计算绘制；历史不足时显示「数据不足 N 天」
- 耗尽预测用本地线性外推，AI 只生成提醒文案并标注「推测」；只在剩余低于阈值时触发；agent 不可用时数字与趋势仍显示
- 刷新遵循 Host cache/rate 提示，不在卡内轮询；说明本卡自己的 AI 调用是否计入用量（以接口口径为准）
- 3x3：剩余额度 + 今日用量 + 入口

**一票否决**

- 编造 token 数或额度
- fixtures 冒充真实用量并标 passed
- 卡内 setInterval 轮询
- AI 不可用时整卡不可用

**夹具 / 断言提示**

- fixtures.responses：正常 / 缺 token 字段 / 未授权 / error
- storage 种子：30 天历史 + 剩余 5% 触发提醒
- agentChecks：提醒 ok / error；阈值以上 callLog=0
